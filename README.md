# Indicadores-Culturales-de-Santurtzi
- Indicadores culturales para apoyar las decisiones municipales de Santurtzi
- Objetivo y utilidad para Cultura:
Reunir definición, procedencia, periodo, fórmula y calidad de cada indicador para revisar la
programación, detectar necesidades de información y documentar las decisiones. La
propuesta combina recursos culturales, acceso y diversidad, respuesta a la programación y
controles transversales de territorio y calidad.
- Problema que aborda:
La información sobre actividades, recursos, ayudas y participación procede de fuentes con
periodos, finalidades y grados de validación diferentes. Sin un criterio común, es fácil
confundir oferta con demanda, subvención concedida con pago o una cifra de demostración
con un resultado municipal.
